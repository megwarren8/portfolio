What a teacher sees

  • Every conversationGrouped by student session, with the exercise the student had open when they asked.
  • Pushback, countedWhen a student demands the answer or claims the teacher allowed it, the page tags the tactic. The TA holds the line either way.
  • Search and exportFilter by date, section, or words in the chat, and download it all as a spreadsheet.
  • Exit ticketsGraded against the lesson’s checked answer key, with the mix-ups that showed up and a draft note for each student, ready for you to edit.

The Lesson Studio

Every lesson in the course is a ready-to-teach class: slides, a teacher screen with notes for each slide, a class timer, a printable handout, and an exit ticket. Three full lessons are open in the sample; the rest of the course is listed and locked.

How the sample stays the same for everyone

The sample class has its own login and reads only its own made-up chats. The server refuses every change to it, so what you see is what the next visitor sees. No real student’s words are anywhere in it.
