Book Commissions

Commission a book that does more than a PDF can.

Megan Warren builds custom interactive textbooks, course books, certification study guides, onboarding guides, and training manuals on commission. Each one is a single HTML file that opens in any browser with no wifi, no login, and no install, and one source forks into a student edition and a facilitator answer-key edition. Four full course textbooks built this way are live and public right now, alongside a companion history web book. Based in Boston, Massachusetts, working remotely.

What I build on commission

Interactive course textbooks
A full course in one file: sections, worked examples, exercises with staged hints, diagrams that respond, and recaps. Built for a class that meets, not for a course platform you have to subscribe to.
Corporate onboarding guides
The same engine behind the textbooks, aimed at a new hire instead of a student. It works offline, so it opens on day one before anyone has sorted out an account.
Certification and study guides
Practice sets with hints that ladder instead of jumping straight to the answer, plus a separate answer-key edition for whoever is running the room.
Training manuals and workbooks
For a workshop, a cohort, or a volunteer program. Print-ready layouts for the workbook and the key come out of the same source as the screen version.
Two editions, one source
The student edition and the facilitator answer-key edition are generated from the same file, so they cannot drift apart. Fixing a typo once fixes it in both.
Accessible math, done properly
Fractions stack as real numerators over denominators, exponents are true superscripts, and the read-aloud says the math out loud correctly. This is the part most tools get wrong.

Questions people actually ask

Is this a course platform?
No, and that is deliberate. It is a book: one file, no subscription, no login, no seat licences, nothing to renew. You own it outright.
Does it only work for math?
Math is the hardest case, which is why the live examples are math books. Onboarding guides, study guides, and training manuals run on the same engine.
Can I get an answer-key edition?
Yes, generated from the same source as the student edition so the two can never disagree with each other.
Can it be printed?
Yes. Print-ready layouts for the book, its worksheets, and its keys come out of the same source as the screen version.
Can it go in a store?
It can. Three of the books above are free on Apple Books: Discrete Math and Linear Algebra, Calculus Derivatives, and Trigonometry. Each is built from the same source file as its web edition rather than exported by hand, so the two cannot drift apart. Worth saying plainly: a store listing is extra scope, not part of every commission, and it is worth it only if your readers are already somewhere you want to be found.
What does it cost?
Between $1,500 and $10,000 for most commissions, fixed and quoted by scope before any work starts. A book usually sits in the upper half of that range.
Do you work outside Boston?
Yes. Remote by default, and the location does not change the price. I am based in Boston, Massachusetts.
